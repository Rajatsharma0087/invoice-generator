## ✨ Planned Features

- 📋 Your details + client details form
- 🔢 Auto-generated invoice number
- 📅 Auto invoice + due date
- ➕ Add/remove line items dynamically
- 🧮 Auto calculate subtotal + tax + discount
- 💱 Multi-currency ($, ₹, €, £)
- 👁️ Live preview as you type
- 📄 Download as PDF
- 🖨️ Print invoice
- 🌙 Dark / Light mode
- 📱 Fully responsive
